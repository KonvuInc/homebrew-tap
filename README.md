# Konvu Homebrew Tap

```sh
brew install konvuinc/tap/konvu
konvu skills install
```

```sh
brew install konvuinc/tap/konvu-telemetry
konvu-telemetry setup
```

Formula source releases are published at [Konvu CLI](https://github.com/KonvuInc/konvu-cli/releases)
and [Konvu Telemetry](https://github.com/KonvuInc/konvu-telemetry/releases).
